About

This is the blog for pathfindR, an R package for enrichment analysis via active subnetworks. Here you’ll find release notes, tutorials, worked examples, and the occasional note on what’s changing under the hood.

pathfindR is developed and maintained by Ege Ulgen. For documentation and function references, head to the package website; for the source and issues, see GitHub.
